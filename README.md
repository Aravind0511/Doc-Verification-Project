# Doc Verification

## OCR and Deep Learning-Based Document Verification With Blockchain-Enabled Tamper Detection

Doc Verification is a document authentication system that combines:

- OCR-based document text extraction
- Deep learning-based semantic verification
- SHA-256 document hashing
- Merkle tree-based integrity verification
- Blockchain-based document registration
- Tamper detection
- Trust score-based verification

## Core Flow

Document Upload
→ Preprocessing
→ OCR
→ Field Extraction
→ Semantic Verification
→ SHA-256 Hash
→ Merkle Tree
→ Blockchain
→ Tamper Detection
→ Trust Score
→ Final Verification
